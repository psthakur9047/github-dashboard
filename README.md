# Pankaj Kumar — GitHub Pages Dashboard

A modern GitHub-style personal dashboard for **Pankaj Kumar (@psthakur9047)**.

## Features
- Responsive GitHub-inspired layout
- Light / dark mode
- Live public GitHub profile statistics
- Live public repository cards using the GitHub API
- Search repositories
- Featured project and social links
- Works as a static GitHub Pages website

## Files
- `index.html`
- `style.css`
- `script.js`

## GitHub Pages
Upload these files to a public repository and enable **Settings → Pages → Deploy from a branch → main → /(root)**.

GitHub Pages looks for an `index.html` entry file in the publishing source.
